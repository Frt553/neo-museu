# Museu de História Natural — versão local

Este pacote contém a landing page atualizada, incluindo o código React/TypeScript, as imagens do acervo, o vídeo do hero, a timeline geológica, o observatório 3D, os modos de leitura e o encerramento cinematográfico.

## Requisitos

- Node.js 20 ou superior
- npm

## Executar localmente

```bash
npm install
npm run dev
```

Depois, abra `http://localhost:3000`.

## Verificar o build

```bash
npm run lint
npm run build
```

Os assets locais estão em `public/assets/neo-museum/`. Esta versão já aponta para esses arquivos e não depende de `/manus-storage/`.
